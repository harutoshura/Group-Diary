#  用法（两种任选）：
#
#  【方式一 · 自动扫描】—— 推荐日常使用
#      本文件只保留注释（就像现在这样），程序会自动扫描 music
#      文件夹（含子文件夹）里的全部音频，按文件名排序播放。
#      也就是说：往 music 文件夹里丢音频 = 增加音源，
#                删掉音频文件        = 减少音源。
#
#  【方式二 · 手动清单】—— 想指定顺序或加入网络电台时使用
#      在下面一行一个地写。写了清单，就完全按清单播放，
#      没写进清单的本地音频不会被播放。
#
#  可写的三种形式：
#      晨间钢琴.mp3                  ← music 文件夹里的文件
#      环境音/雨声.flac              ← 支持子目录
#      https://example.com/a.mp3    ← 网络直链 / 网络电台
#
#  支持的格式：mp3 wav ogg oga m4a aac flac opus weba
#  以 # 开头的行是注释，会被忽略。
