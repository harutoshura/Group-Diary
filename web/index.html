        第一次使用？点这里看三步说明
        
    
          
  1. 在 GitHub 上新建一个空仓库（私有也行），把地址填到上面的「仓库地址」。
    2. 
          
  2. 生成访问令牌：GitHub → Settings → Developer settings → Personal access tokens → Fine-grained token，权限给该仓库的 Contents: Read and write，粘贴到「访问令牌」。
    3. 
          
  3. 点「保存并绑定远程」→「一键同步」。之后每次写完日记点一次「一键同步」即可。
    4. 
        

        
其他人加入：把本文件夹（或本程序压缩包）给对方，填同一个仓库地址与自己的令牌，点「从远程克隆」；之后用「一键同步」共享。

        
📖 完整图文步骤见同目录下的 GitHub同步操作指南.md，里面有建仓库、生成令牌的逐屏说明和报错对照表。

        
🔌 连不上 GitHub？把上面的「代理模式」改成「自动（读取 Windows 系统代理）」，
        点「应用代理设置」再点「一键同步」。如果你的网络本来就能直连，就选「不使用代理」。
